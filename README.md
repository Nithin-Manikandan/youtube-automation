# Shorts Factory

Fully automated, free-to-run pipeline that makes vertical AI videos (YouTube Shorts):

```
topic (LLM) -> script (LLM) -> AI image per scene -> narration + word timings -> procedural dark score
   -> cinematic camera moves, grade, grain, animated captions -> 1080x1920 MP4 -> (optional) YouTube upload
```

Runs on GitHub Actions, so nothing needs to be on your computer. Every piece has a free tier.

| Step | Free provider | Key needed |
|---|---|---|
| Topic + script | Gemini (falls back to Groq, then OpenRouter) | `GEMINI_API_KEY` |
| Images (FLUX) | Pollinations, then Cloudflare Workers AI, then Hugging Face | none / optional |
| Voice | Microsoft Edge neural voices via `edge-tts` | none |
| Music + SFX | generated by maths in `pipeline/audio.py` | none |
| Video assembly | FFmpeg (bundled) | none |
| Hosting/scheduling | GitHub Actions | none |

## 1. Look at a video (5 minutes)

1. Get a free key at <https://aistudio.google.com/apikey>.
2. In this repo: **Settings > Secrets and variables > Actions > New repository secret**, name `GEMINI_API_KEY`.
3. **Actions > Generate video > Run workflow** (leave "upload" off). The workflow file must be on the repo's default branch for the button to appear, so merge this branch first.
4. When it finishes (about 5-8 minutes), open the run and download the **video** artifact. It holds the MP4, a contact sheet of stills (`.jpg`) and the script (`.json`).

Nothing is posted anywhere at this stage.

## 2. Tune it

Everything that shapes the result is in [`channel.yaml`](channel.yaml): niche, image style, voice, caption look, camera movement, grain, colour grade, music level. Change one thing, run again, compare.

- Images look generic or inconsistent -> edit `visuals.style`, or the image-prompt rules in `pipeline/script.py`.
- Voice too robotic or slow -> change `voice.name` / `rate` / `pitch`.
- Too static or too shaky -> `zoom_strength`, `shake`.
- Script is weak -> `script.extra_rules`, or `niche`.

If Pollinations is slow or rate-limited, add Cloudflare Workers AI secrets (`CF_ACCOUNT_ID`, `CF_API_TOKEN`, free daily allowance) or `HF_TOKEN`; the chain tries them automatically.

## 3. Automate posting (after you like the videos)

1. Google Cloud Console: create a project, enable **YouTube Data API v3**, create an OAuth client of type **Desktop app**. Add yourself as a test user on the consent screen.
2. Locally: `pip install requests`, then `python tools/youtube_auth.py CLIENT_ID CLIENT_SECRET`. Copy the printed refresh token.
3. Add secrets `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN`.
4. Run the workflow with **upload** ticked. Videos go up **private** (see `upload.privacy`) and flagged as synthetic media. Check one in YouTube Studio.
5. When happy, set `privacy: public` and uncomment the `schedule:` block in `.github/workflows/generate.yml`.

Projects left in "Testing" mode have refresh tokens that expire after 7 days; publish the consent screen to "In production" to avoid that. Uploads from an unaudited API project may be locked to private until Google audits it.

## Run locally

```bash
pip install -r requirements.txt
python -m pipeline.make --offline          # engine test: placeholder art, silent voice, no network
GEMINI_API_KEY=... python -m pipeline.make # real run
```

`--offline` only tests motion, captions and sound. Its backgrounds are placeholders, not real AI images.

## Known limits

- Images are AI stills animated with camera moves, not text-to-video clips. Truly generated video is not free at volume. `pipeline/images.py` is the place to add a paid video model later.
- Free image models can produce hand/face artefacts. Dark, foggy, silhouette-heavy prompts hide most of it.
- The real image and voice steps have not been tested end to end yet; expect to tune after the first run.
- Monetisation needs 1,000 subscribers plus 10M Shorts views in 90 days (or 4,000 watch hours). Repetitive mass-produced content can be demonetised, so keep scripts varied.
